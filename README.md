# Personal Profile Page — Mini Project 1

A single-page responsive personal profile site built with semantic HTML5 and CSS3.

## Structure
```
mini-project-1/
├── index.html
├── style.css
└── images/
    └── profile.jpg
```

## Before you submit

1. Open `index.html` and replace:
   - `Ayesha Rahman` with your own name (appears in the title, header, hero, and footer).
   - The bio text, skills list, and project descriptions with your own.
   - `ayesha.rahman@example.com` with your real email (used twice).
2. Replace `images/profile.jpg` with your own photo (same filename, or update the `src` in `index.html`).

## Run it locally

Just open `index.html` in a browser — no build step needed.

## Deploy with GitHub Pages

1. Create a new GitHub repository and push these three files/folders to it.
2. In the repo, go to **Settings → Pages**.
3. Under "Build and deployment", set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. Save. Your live URL will appear at the top of that page after a minute (usually `https://<username>.github.io/<repo-name>/`).

## What's already done

- Semantic tags: `header`, `nav`, `main`, `section`, `footer`.
- Flexbox and CSS Grid for layout (nav, hero, skills, project cards, contact).
- Media queries for mobile at 800px and 560px breakpoints.
- Alt text on the image and `<label for>` on every form field.
- Separate `style.css` file, no inline styles.
